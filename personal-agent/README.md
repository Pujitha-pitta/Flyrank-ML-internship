# Pujitha AI Portfolio Assistant

## Overview

The Pujitha AI Portfolio Assistant is a personal AI agent designed to answer questions about my education, technical skills, research, projects, internship experience, and career interests.

The assistant uses a structured knowledge base to provide accurate, concise, and professional responses for recruiters, hiring managers, collaborators, and visitors.

## Features

- Answers questions about my background
- Summarizes technical skills
- Explains machine learning and AI projects
- Describes research experience
- Shares GitHub and portfolio links
- Uses only verified information

## Files

- `agent_prompt.md` – Defines the assistant's role, goals, tone, and rules.
- `knowledge_base.md` – Contains verified information used to answer questions.
- `sample_questions.md` – Example prompts that demonstrate the assistant's capabilities.
